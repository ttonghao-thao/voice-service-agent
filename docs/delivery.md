# 产品需求与交付边界

类型：已确认需求。实际实现看 [architecture.md](architecture.md)，缺口和顺序看 [方案](implementation-plan.md) / [任务板](TASK_BOARD.md)，测试结果只看 [validation.md](validation.md)。

## 1. 三类查询与通用知识兜底

2026-11-23 确认：本系统同时提供以下三类能力，不存在仅启用 search_knowledge 的产品场景。依赖暂未接入、测试只覆盖部分能力、旧 Provider 只实现部分工具，均是实现/验收范围限制，不能变成新的产品模式。

| 能力 | 供应商 / 内部路由 | 交付要求 |
| --- | --- | --- |
| 天气查询 | QWeather / WEATHER | 使用真实实况或适用日期预报，地点和日期不足时澄清，不猜用户位置或冒充实时天气 |
| 通用知识查询 | Tavily / WEB_SEARCH | 查询获准公开发送的独立问题，保留标题/URL，承担公开知识检索和受控兜底 |
| 专业知识库查询 | CueKB / CUEKB | 保留原问题、型号、版本、否定与条件，执行授权 evidence query/validate，展示可复核来源 |

普通闲聊和不需要检索的稳定常识可以由语音模型直接回答，但不算已查询。通用知识兜底不是所有失败后的默认工具：明确属于公开知识且无敏感上下文时可检索；专业问题不能仅因型号可能公开就外发。CueKB/天气服务异常、权限拒绝、未知意图、参数缺失或没有原生委派，不能自动搜索公网。内部资料、客户数据、日志、账号、SN 和个人信息不自动外发；资料属性不明先澄清。公开来源不认证企业内部事实。

## 2. 语音、角色与权限

浏览器支持麦克风和 PCM WAV 的全双工、多轮、停顿与打断。门户沿用英文；Sophon 按 SOPHON_LIVE_LOCALE 验证中文或英文。Sophon、NVIDIA VoiceChat、CueKB 保持独立部署。VOICE_PROVIDER 必须单选 sophon_live 或 nvidia，默认只配置 Sophon；本期只验证 Sophon，不要求 NVIDIA 服务/GPU 验收。主交付链路使用 Sophon Live + LiveKit 支持三类查询。

Sophon 直接理解音频并原生 delegate(task)，Router 只解析已收到的 task，音频活动/窗口确认输入归属。2026-11-23 用户确认使用 qwen3.7-flash 替代自然语言规则解析，结构化任务仍直接校验；模型只能返回受限意图/参数，不能生成业务答案或扩大权限。ASR 只用于字幕、记录和诊断；关闭、迟到、空或错误 ASR 不参与授权、触发、选工具或必需参数提取。未关联字幕可以显示，不能绑定成业务输入。禁止关键词补调、伪造事件、强制 WS tool_choice 或另建 Agent Runtime。

外部意图模型只接收当前原生 task，不读取 ASR、历史、证据、身份或凭据。私有/敏感 task 和已回填企业资料的 Room 不自动发给该模型。模型错误、超时、改写关键参数或输出不合约时不执行工具，不静默回退规则。模型等待结束及提交前复核输入窗口，新增/补充发声不能误用旧意图。

默认角色“闹闹”的 Persona 精确为：

```text
你是闹闹，一个开朗，幽默的语音伙伴，说话简短而自信，像朋友之间的聊天
```

角色按用户隔离持久化，支持新增/编辑/选择/删除/恢复默认和最终 Instructions 预览。Persona 与服务端固定委派规则分开；新会话保存快照，编辑或删除不热改活动会话，异常回退默认。validation 模式沿用临时通话身份，不增加跨用户或跨通话共享权限。

身份、凭据、KB 范围、工具许可由服务端维护；Coordinator 唯一业务提交，提交/回传复核 epoch、revision、Turn、租约、权限和工具版本。普通发声/Stop playback 不取消查询；明确取消/换题按生命周期结清，未知发送状态不自动重发。

## 3. 发布与验收要求

系统按容器发布：LiveKit 与 Redis/PostgreSQL/API/Web 在同一 Compose，API/Web 独立镜像、migrate 复用 API 镜像、PostgreSQL/Redis 持久卷；Sophon/CueKB 独立部署。配置变化重建相应容器，推送 Git 不等于部署完成。详见 [部署手册](deployment.md)。

验收分别记录原生触发、Router 解析、工具真实结果、Commentary 回执、后续候选音频、实际听音与语义/问题覆盖。Gateway 接收、首段等待语、字幕、audio.done 和播放器排空均不能独立证明最终回答正确。

原生触发与 Router 解析必须分别统计，不能只改 Router 就声称工具调用解决。两类历史故障已在固定官方录音集分别修复并复测，原始失败与修复后两张 14 项表保留在 [已解决记录](validation.md#5-已解决原生委派触发与-router-解析)，不列作当前待修复任务。官方分类与时间/灯光/记忆等超出三类查询的范围分开统计；真实失败不回退 mock，不以模拟或成功个例替代整组语音复测。

三类真实服务、角色、ASR 开关对照、固定录音重复、多轮打断、隐私兜底、来源与实际听音均需证据。原始失败和后续复测事实只维护在 [验证记录](validation.md)。后台持续播报暂缓；旧 legacy/SDK/NVIDIA 兼容代码的存在不是完整能力或无限连续通话承诺。
