## 当前实现基础

已有 FastAPI 会话 API、HTTP/SSE/WSS、VoiceChat native bridge、单写入器、票据、epoch/revision 隔离、BusinessRuntime、CueKBAdapter、ToolRegistry、PostgreSQL/Redis 接入、AudioWorklet 及简单客户门户。

客户页面已移除工具管理工作台；客户/operator/admin 仍由服务端权限区分。知识工具使用 CueKB `/v1/search`；部署白名单与管理员启停共同约束工具，CueKB-only 不要求天气。硬打断保留为兼容接口，门户已将停止播报、取消查询和结束语音分开；默认 105 秒在安静边界自动轮换。

## 实施约束与暂缓项

- 编码阶段不调用 CueKB/VoiceChat 真实服务；使用接口规范和受控响应/事件夹具验证逻辑，不将测试替身结果写为真实能力通过。
- Dockerfile、Compose、镜像制作与启动代码仅按需静态检查；不安装 Docker、不搭建环境、不拉取/构建镜像、不启动容器。D07 的执行留待部署阶段。
- D05 需要新增任务状态/版本时使用 Alembic；保留历史数据兼容，不用 create_all 替代迁移。
- schema/协议随实际代码同步导出，不能只改 JSON 声称新接口已经实现。
- KnowledgeAgent 仅在复杂知识样本证明收益后加入；首期不增加递归多 agent 或新队列服务。
- 本期只支持英文；中文待语音模型具备能力后再定义本项目支持范围。不更换语音模型、不建设 CueKB 索引，不在本轮增加 WebRTC/SIP、支付交易或公开匿名管理入口。
- 本期只启用知识库。天气/股票供应商不属于本期需求；后续明确业务选择后再评估接入。
- 用户确认新需求时修改负责该主题的文档与本表，避免再建立第二份总设计或长期追加聊天纪要。
