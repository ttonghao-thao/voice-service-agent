# 当前关键取舍

基线 `2a8ba8b`。具体行为只维护在[架构](../architecture.md)，已知问题在[任务板](../TASK_BOARD.md)。

| 取舍 | 当前理由与代价 |
| --- | --- |
| 独立 VoiceChat/CueKB，Coordinator 唯一提交 | 保留权限和审计边界；跨服务没有共同事务 |
| 原生选工具，无附加路由模型 | 保留当前产品技术路径；不能保证企业首问每次触发工具 |
| 单输入一次问题级 query | 缺项召回归 CueKB；终态后调用只结清，不重查 |
| 完整组 + 精确最终包预算 | 不截断条件，不估算 tokenizer；小预算可能降为部分答案或拒答 |
| 输入/播放/业务分离 | 用户发声只停止播放；注入期间 ASR 领先不等于理解/回答完成 |
| 播后有限检查 | 当前原生音频不能保证播前核验；漏项及语义检查缺陷必须单列，不能把 source_checked 当作事实认证 |
| 配套快照部署 | model/data/audio_server 与 API/Web 版本匹配；不单独热替换某个文件后宣称通过 |

两次检索、终态后立即报工具循环、模型 query 替代 ASR 等旧方案已被替代，禁止据旧文档重新引入。逐 token 消费、related-input 自动结清和固定连接寿命仍存在，已列待优化而非视作长期正确设计。
