更新：2026-10-04。代码基线：`codex/q1003` / `2ea8cfe`（SIM/CTX1/EVAL1/REL1），已推送到同名远端分支并核对 SHA。架构见 [architecture.md](../2026-10-07/architecture.md)，实施细节见 [Q07](../2026-10-07/qa-routing-design.md)，执行证据见 [验收](../2026-10-07/acceptance-report.md)。任务状态只在本文件维护，历史过程保留在验收记录。

## 1. 当前结论与审计基线

本项目是可配置知识约束的英文实时语音问答系统，客服为首个场景。Q07 原生双工具基础实现与 Q06 统一聊天展示已完成本地验证；API/Web 构建及隔离 PG/Redis/Compose 基础检查已通过。D07/Q07-E 的真实模型、CueKB、GPU、生产环境恢复和实际听音仍未验收。

| 当前事项 | 已确认状态 |
| --- | --- |
| 默认模式 | legacy：VoiceChat 注册 consult_service_agent，完整输入进入既有外置知识链 |
| 可选新模式 | dual_tools：首版仅注册 lookup_knowledge / reason_over_knowledge；可信工具注册支持后续扩展 |
| 策略 | 新模式默认 general_qa，允许无工具一般回答；knowledge_required 拒绝无工具实质性输出，lookup 也走外置执行 |
| 选路 | VoiceChat 原生 tools/instructions 决策；不向其 WS 发送 tool_choice，不新增语义分类器 |
| 后台知识能力 | ENABLED_TOOLS=search_knowledge；两个原生工具均依赖 Registry/CueKB，名称属于不同层 |
| 直查与复杂执行 | sufficient 完整证据交 Nano D2 续答；必要时升级一次，共享期限和最多两次逻辑检索；复杂执行用外置 LLM |
| 输出与数据 | 一般问答保存 Utterance/实际字幕，不建知识 Turn；D2 事后有限检查；工具结果写回有 DeliveryAttempt，崩溃 unknown 不重发 |
| 版本与部署 | Alembic 最新 0008；内部来源上下文/任务快照；每次通话独立 capability；Web HTTPS 8087、同源 /api/；API 不映射宿主端口 |
| 验证口径 | 最新应用：207 Python（含 42 项既有独立 API 网络用例及 10 项连续序列）、12 Node、10 Chromium、Ruff/构建通过；本轮重跑 6 项部署/迁移测试、实际镜像构建与 16 项隔离 Compose 检查；不替代真实服务验收 |

D2 不能撤回已播内容，也不能证明完整语义或实际音频正确；外置路径播前校验的是拟口述文本。general_qa 的提示词无法保证企业问题零漏调用，服务端工具网关也不能捕捉所有未产生的 tool call。部署放行必须记录实际选路、内容和语音结果。

自然插话/停顿由模型处理，speech_started 不自动取消业务。停止播放、取消任务、上游推理取消分别处理；保留 revision/epoch/租约、唯一提交、单写入器与 pending call 结清。当前 speech 基线的 WebSocket 修复及 Jinja 配置见 [交付说明](../../../deploy/voicechat/README.md)，不改模型/离线转换。

## 5. 实施约束与暂缓项

- 工程边界以 [AGENTS](../../../AGENTS.md) 为准；真实环境缺失不阻塞契约编码，不能据此声称生产验收完成。
- 当前是英文一般问答及授权知识服务；中文、天气/股票、WebRTC/SIP、交易、其他 Provider 和正式客户认证不在已实现范围。
- 不新增语义分类器、独立 Nano 服务、子任务/多 Agent 调度或队列；KnowledgeAgent 仅在复杂样本证明收益后评估。
- 自然声学插话、播放停止、业务取消和上游取消分开；不以任意口述文本或 ASR 关键词冒充已执行控制。
- 实际接口/schema 变化才导出契约；文档任务仅修改 Markdown，历史快照不重写，新需求归既有主题文档与本板。
